# Task 1: Data Cleaning and Preprocessing

## Data Analyst Internship

### Objective
The objective of this task is to clean and preprocess a raw dataset containing missing values, duplicate records, inconsistent text formats, and date formats.

## Tools Used
- Python
- Pandas
- Pydroid 3

## Dataset
A sample customer dataset was used for data cleaning and preprocessing.

## Data Cleaning Steps

The following steps were performed:

1. Identified missing values in the dataset.
2. Removed duplicate rows.
3. Cleaned and standardized column names.
4. Standardized gender values such as Male and Female.
5. Standardized country names.
6. Filled missing age values using the average age.
7. Converted dates into a consistent format (DD-MM-YYYY).
8. Handled missing gender values.
9. Checked and corrected data types.
10. Saved the cleaned dataset as a CSV file.

## Files Included

- `task1.py` – Python code used for data cleaning.
- `cleaned_dataset.csv` – Cleaned dataset.
- `README.md` – Description of the task and cleaning process.

## Result

The raw dataset was successfully cleaned and preprocessed. Missing values, duplicate records, inconsistent formats, and column names were handled to make the dataset ready for further analysis.

## Conclusion

This task demonstrates basic data cleaning and preprocessing using Python and Pandas. The cleaned dataset can now be used for data analysis and visualization.
